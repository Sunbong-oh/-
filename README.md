# 👑 Princess English Quiz

4살 아이를 위한 공주 이야기 영어 퀴즈 게임 6개입니다.

- 영어 질문과 선택지 두 개를 미국 영어로 읽어 줍니다.
- 아이가 🎤 버튼을 누르고 정답 단어를 영어로 말하면 맞았는지 확인합니다.
- 날짜에 따라 매일 다른 미션과 질문이 나옵니다.

| 게임 | 폴더 |
|---|---|
| 🍎 Snow White (백설공주) | `snow_white/` |
| 🌹 Sleeping Beauty (잠자는 숲속의 공주) | `sleeping_beauty/` |
| 👠 Cinderella (신데렐라) | `cinderella/` |
| 🧜‍♀️ The Little Mermaid (인어공주) | `little_mermaid/` |
| ❄️ Frozen (겨울왕국) | `frozen/` |
| 🏮 Rapunzel (라푼젤) | `rapunzel/` |

## 사용 환경
- 음성 듣기·말하기는 브라우저 기능을 씁니다. **크롬(Chrome)** 에서 가장 잘 됩니다.
- 처음 🎤를 누를 때 마이크 허용을 눌러 주세요.

GitHub 저장소의 Settings → Pages → Branch: `main`, 폴더: `/ (root)` 로 설정하면
`https://<아이디>.github.io/<저장소 이름>/` 에서 열립니다.
